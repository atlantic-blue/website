# Audit, August 2026

Audited on 18 August 2026, against production and against the repository at commit `8cbedfd`.
Repository: https://github.com/atlantic-blue/website
Live site: https://atlanticblue.solutions
Last deploy: 8 February 2024 (commit `8cbedfd`, 77 commits total).

All numbers below are measured, not estimated. The method is stated next to each one.

---

## 1. What the site is today

One page. 273 words. Three headings. One link, and that link is an anchor to the same page.

The page renders on the server from an Amazon Web Services Lambda function. React and react-router build the
markup, react-helmet writes the head. CloudFront sits in front. Static files live in Amazon S3
under `/public/`.

The company sells software development. The page gives the visitor no way to buy it.

### The full inventory of the site

- `/` home, English.
- `/es`, `/fr`, `/pt`, `/ru` the same home page, translated.
- `/help` a page whose entire content is the text "I am a help page".

That is everything.

## 2. Faults found

I grouped these by what they cost. Each one names how I measured it.

### 2.1 The visitor cannot contact the company

There is no email address, no telephone number, no form, no booking link and no address on the
page. The single link is `href="#about"`.

The address `hello@atlanticblue.solutions` does exist. It is defined in
`infrastructure/www/vars.tf` and a Go Lambda forwards it to a Gmail account. The website never
shows it.

This is the largest fault. Every other fault costs traffic. This one destroys the traffic that
already arrives.

### 2.2 Search engines cannot index the site properly

Measured with `curl` against production on 18 August 2026.

- `/robots.txt` returns the home page markup, 27,864 bytes, content type `text/html`. The real
  robots file is deployed to `/public/assets/robots.txt`, where no crawler looks.
- `/sitemap.xml` returns the same home page markup. There is no sitemap.
- Every unknown path returns HTTP 200 with the home page. I tested `/nonsense-xyz`, `/blog`,
  `/services`, `/contact` and `/about`. All returned 200. The Lambda handler in
  `packages/www-lambda/src/server/lambdaHandler.ts` hard codes `statusCode: 200`, and CloudFront
  maps 404 and 403 to 200 as well. Google calls this a soft 404 and treats the whole site as low
  quality.
- All five language pages send the same canonical link, `https://atlanticblue.solutions`. So the
  Spanish, French, Portuguese and Russian pages each tell Google to ignore them and index the
  English page instead. Four of the five language pages can never rank.
- There is no `hreflang` markup at all.
- There is no `h1` on the page. The hero title is an `h2`.
- There is no structured data. No JSON for Linked Data of any kind.
- There is no Open Graph or Twitter card markup, so any share on LinkedIn or Slack renders bare.
- The `keywords` meta tag is present. Search engines ignored it many years ago.
- The site is not in any directory. A search for the brand returns the home page and then unrelated
  companies. There is no LinkedIn company page, no Clutch profile and no Google Business Profile.
  A United States company called Atlantic Blue at `atlanticblueassociates.com` competes for the
  same brand name in search results.

### 2.3 The site is slow and expensive to serve

Measured with `curl` from a Paris CloudFront point of presence.

- Total image weight is 9,122,121 bytes, which is 9.12 MB. I downloaded every image and added the
  bytes.
- The images are full resolution camera files served without resizing:
  - `custom-software.jpg` 3.79 MB at 4000 by 6000 pixels, displayed as a small card.
  - `screen.jpg` 1.65 MB at 5184 by 3456 pixels.
  - `tech-support.jpg` 1.06 MB at 5184 by 3456 pixels.
  - `agile-methodology.jpg` 1.25 MB at 4032 by 3024 pixels.
  - `setup.jpg` 0.55 MB at 3353 by 2514 pixels.
- The favicon is a 407 KB PNG file at 672 by 698 pixels.
- No image has `width`, `height`, `loading="lazy"` or a `srcset`. There is no WebP or AVIF.
- `vendor.js` is 1,750,598 bytes raw and 409,166 bytes compressed. Total script and stylesheet
  transfer is 453,914 bytes. That is a large payload for a page with no interactive feature except
  a language menu.
- Every response carries `x-cache: Miss from cloudfront`. I requested the home page three times and
  every stylesheet, script and image once. Not one response was a cache hit. The cause is in
  `infrastructure/www/www_lambda_cloudfront.tf`: both cache behaviours set `min_ttl`, `default_ttl`
  and `max_ttl` to zero. The content delivery network caches nothing, including the images.
- No response carries a `cache-control` header, so browsers cannot cache the 9.12 MB either. A
  returning visitor downloads everything again.
- Brotli compression is not served. I requested with `Accept-Encoding: br` and got no
  `content-encoding` back.
- Time to first byte measured 0.37 s, 0.45 s and 0.58 s across three requests. Every one of those
  invoked the Lambda function, because nothing is cached.

The effect on Core Web Vitals is direct. The Largest Contentful Paint element is a 1.65 MB hero
image that is never cached and never resized.

### 2.4 Security and legal exposure

- No security headers at all. I read the full response headers. There is no
  `strict-transport-security`, no `x-content-type-options`, no `content-security-policy`, no
  `referrer-policy` and no `permissions-policy`.
- The minimum viewer protocol is `TLSv1.1_2016` in `www_lambda_cloudfront.tf`.
- Mixpanel starts on every page load in `packages/www-lambda/src/analytics/mixpanel.ts` with
  `debug: true`, `track_pageview: true` and `persistence: 'localStorage'`. There is no consent
  banner, no privacy policy and no cookie policy. United Kingdom law, through the General Data
  Protection Regulation and the Privacy and Electronic Communications Regulations, requires consent
  before storing that identifier. `debug: true` also writes tracking logs to the visitor console in
  production.
- The footer shows only "© 2026 London, UK". A United Kingdom limited company must show its
  registered name, company number and registered office address on its website. The company is
  ATLANTIC BLUE SOLUTIONS LTD, number 14468993, registered at 86-90 Paul Street, London, EC2A 4NE,
  incorporated on 8 November 2022.
- The page shows the Sky, DAZN and Peacock marks under the heading "Our Customers". There is no
  case study, no named engagement and no statement of permission behind any of them. This needs to
  be either evidenced or removed. It is the strongest asset on the page and the weakest claim.

### 2.5 Accessibility

- No `h1`, so the document has no top level heading.
- No skip link.
- Two images carry `alt="screen"`, which describes nothing.
- The language menu in `packages/www-lambda/src/components/Dropdown/Dropdown.tsx` puts `onClick` on
  plain `li` elements. There is no `role`, no `aria-expanded`, no keyboard handler and no focus
  management. A keyboard user cannot change language.
- The client logo row includes an empty `div` styled with a background image for Sky. It carries no
  text alternative.

### 2.6 Design

- `font-family: Roboto` is declared in `App.scss`. Roboto is never loaded. There is no `@font-face`
  and no font link in the head. Most visitors see the system fallback.
- There is one breakpoint in the entire stylesheet set, `max-width: 600px`. There is no tablet
  layout.
- There are no design tokens. Colours are written inline as literals across files.
- The brand blue is `#0092CA` in the logo. The call to action button is `rgb(175, 24, 78)`, a
  crimson. Nothing connects the two.
- No dark mode, no motion preferences, no focus styles.
- The hero title is 72 pixels on desktop and 35 pixels below 600 pixels wide, with no scale between.

### 2.7 Repository and delivery

- Three packages exist. Two are dead: `packages/app` (an older single page application) and
  `packages/www-static` (an abandoned Gatsby build). Only `packages/www-lambda` ships.
- `.github/workflows/deploy.yml` ends with `terraform plan`. It never runs `terraform apply`. So
  infrastructure has not shipped from the pipeline at all. Any live infrastructure change was
  applied by hand.
- The pipeline authenticates with long lived `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`
  secrets. It should use OpenID Connect.
- The pipeline never invalidates the CloudFront distribution after `aws s3 sync`.
- There are no tests anywhere in `www-lambda`. There is no linter and no formatter in the pipeline.
- The Lambda function URL uses `authorization_type = "NONE"`, so the origin is reachable directly,
  bypassing CloudFront. A `TODO` in `www_lambda.tf` already notes this.
- The repository has no description, no homepage link, no issues and no open pull requests.

### 2.8 Content

The copy is generic. It uses "Elevate", "cutting-edge", "seamless integration", "innovative
solutions" and "high-quality". It names no person, no price, no process, no client outcome and no
number. It could belong to any of the several hundred agencies in London.

## 3. Competitor research

I profiled each competitor with the same script: fetch the home page, count words, count headings,
read `/robots.txt` and `/sitemap.xml`, extract structured data types, and list internal paths.
Measured on 18 August 2026.

### Square Root Solutions, square-root.co.uk
WordPress. 58 internal paths from the home page. Structured data for WebSite, SiteNavigationElement,
Service, LocalBusiness, FAQPage and Organization. 3,686 words on the home page. Contact form and
cookie banner. Title reads "Custom Software Development Company London, UK | 300+ Projects".
Home page headings are framed as customer problems: "Manual Processes Slow Teams Down", "Legacy
Software Is Expensive to Maintain". It runs a page for each technology and each city phrase, for
example `/reactjs-development-company-london-uk/` and `/hire-full-stack-developers-london-uk/`.

### Foundry 5, foundry-5.com
29 internal paths and 29 sitemap entries. A page for each service, each industry and each portfolio
item, for example `/industries/fintech-software-development` and `/portfolio/gather`. 1,563 words on
the home page. Opens with the buyer's fear: "Your last agency vanished", "Your MVP took 6 months".
Publishes a privacy policy.

### Tech Alchemy, techalchemy.com
Next.js. 83 sitemap entries. A downloadable portfolio in PDF form at `/Portfolio-2025.pdf`. Blog at
`/blogs`. Structured data for WebSite. Google Tag Manager present. Narrow positioning on Web3 and
blockchain.

### Cyber-Duck, cyber-duck.co.uk
302 sitemap entries. Sector pages for healthcare, public sector, finance and education. Named client
stories including Bank of England, Sport England, National Highways and the Financial Ombudsman
Service. 51 internal paths. Contact form and cookie banner.

### thoughtbot, thoughtbot.com
The strongest technical example. `cache-control: max-age=86400, public, stale-while-revalidate`
and a Cloudflare cache hit, so the page is served from the edge. 92 KB of markup, the smallest of
the set. 42 internal paths. Structured data for OnlineBusiness and WebSite. It sells through a
public playbook, open source work and case studies with outcomes.

### Hiyield, hiyield.co.uk
Segments by buyer rather than by technology: `/solutions/startup-founders/`, `/solutions/charities/`,
`/solutions/marketing-managers/`. Adds location pages for Bristol and Cornwall. Full legal set:
privacy, cookie, accessibility and terms.

### The comparison

Internal pages reachable from the home page: Square Root 58, Cyber-Duck 51, thoughtbot 42, Hiyield
33, Foundry 5 29, Tech Alchemy 7 with 83 in the sitemap. Atlantic Blue: 1.

Sitemap entries: Cyber-Duck 302, Tech Alchemy 83, Foundry 5 29, others use a sitemap index.
Atlantic Blue: none.

Structured data types: Square Root 6, thoughtbot 2, Tech Alchemy 2, Cyber-Duck 0. Atlantic Blue: 0.

Home page words: Square Root 3,686, Foundry 5 1,563, Cyber-Duck 1,466, Hiyield 947, thoughtbot 835.
Atlantic Blue: 273.

Every competitor has a contact route on the home page. Atlantic Blue has none.

### What the market data says

80 per cent of business buyers use case studies during research and 73 per cent call them a key
factor in the decision. The absence of a named client or a specific number disqualifies a case
study. 51 per cent of software buyers now start research with an AI chat tool more often than with
Google, and 71 per cent use one somewhere in the process. Visitors referred by AI tools convert at
about 4.4 times the rate of organic search visitors. 93.67 per cent of AI Overview citations link to
a page that already ranks in the top ten organic results, so classic search work remains the
foundation. Structured data raises the chance a page is selected by a language model but does not
create authority on its own.
